What the file must look like

The “STUDENT LIST” workbook from SDMS works as it is: one sheet per class, with the lines Grade:, Combination: and Class: at the top, then a table with the columns #, Student Code and Names.

The student code becomes the registration number printed on the report. The combination decides the level (subject list) of the class.

You can import the same file again later, or a newer one: students who are already in the system are not added twice.
