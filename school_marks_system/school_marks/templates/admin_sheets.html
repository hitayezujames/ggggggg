How it works

  1. Download the workbook of a class below (Class workbook (Excel)).
  2. Put it on Google Drive: drive.google.com → New → File upload → choose the workbook. Open it, then File → Save as Google Sheets.
  3. Share it with the teachers of that class: Share → type each teacher's email as Editor (or Anyone with the link → Editor) → Copy link and send it. Each teacher opens the tab of their own course (the tabs at the bottom, named after the course) and types the marks in the white boxes. Google saves by itself. A test is added in a green column: its name in row 5, what it is out of in row 6.
  4. Check the Summary tab: it adds up the tests of every course for every student (total, %, position), as on the periodical report.
  5. Bring it back: in Google Sheets File → Download → Microsoft Excel (.xlsx), then import that file below.
  6. Print: Periodical reports PDF next to the class.

Teachers must not change the student codes (column B) or the title in cell A2 of a tab: that is how the system knows the class, the course and the students. Sorting the rows is fine. To stop a teacher from typing in another teacher's tab, in Google Sheets right-click a tab → Protect sheet → Set permissions.

Import the filled-in workbooks

Only Excel files are accepted. Every course tab is checked first and imported completely or not at all: you see which courses came in and, for the others, which cell to correct. Importing the same workbook again later only brings in what changed, so you can import it as often as you like.
